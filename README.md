# OnePieceRogue

Roguelike web game prototype inspired by the node/run structure of Pokelike and themed around One Piece.

## MVP implemented

- React + TypeScript + Vite foundation
- East Blue node map
- Starter crew: Luffy, Zoro, Nami
- Battle loop with attack/heal
- Berries reward economy
- Treasure, event and rest nodes
- Arlong boss prototype
- Responsive layout

## Development

npm install
npm run dev
npm run build

## Hosting

Designed for a static frontend deploy through Cloudflare, with GitHub as the source repository.
